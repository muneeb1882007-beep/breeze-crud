# Laravel + Vue.js Breeze Authentication CRUD

A lightweight task management application built with Laravel 11, Breeze, Inertia.js, and Vue 3.

## Features
- User Authentication (Login/Register)
- User-specific CRUD operations
- Responsive UI with Tailwind CSS

## How to Run
1. `composer install`
2. `npm install`
3. Set `.env` database details
4. `php artisan migrate`
5. `php artisan serve` & `npm run dev`
